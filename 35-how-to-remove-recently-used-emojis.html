How to Remove Recently Used Emojis

Written by Bavum, Builder and Editor at Mojitap · Published July 29, 2026 · Reviewed with current Apple, Google, Samsung, and Microsoft documentation · About 11 minutes

Most emoji keyboards keep a shortcut list of characters you used recently or frequently. The difficult part is that this list is not managed the same way on every device. Some platforms provide a clear command, some only offer a wider keyboard reset, and some do not document an emoji-only deletion option at all.

Before resetting anything, identify where the unwanted emoji appears. A recent list inside the iPhone keyboard, Gboard, Samsung Keyboard, the Windows emoji panel, the Mac Character Viewer, or a messaging app can be stored separately. Clearing one list may not change another.

The direct answer

You usually cannot press and delete one emoji from a system keyboard's recent list. On Mac, Apple provides a documented Clear Frequently Used Characters command. On iPhone, Android keyboards, and Windows, the available controls are more limited or broader than an emoji-only delete button.

The safest first option is to use other emojis until the unwanted item moves out of the visible list. Use a keyboard reset only after checking what other learned words, preferences, or cached data it may remove.

First decide what you want to remove

One emoji

Remove a single unwanted item

Most system keyboards do not offer a long-press menu or delete button for one recent emoji. Using other emojis is usually the least disruptive way to replace it in the visible list.

Whole list

Clear every recent emoji

Mac provides a direct command. Other platforms may require a broader keyboard or app reset, and the official documentation may not promise that the action targets only emoji history.

Suggestions

Stop emoji suggestions while typing

This is different from recent history. Some keyboards have a separate setting for emoji suggestions or personalization. Turning suggestions off may leave the recent category unchanged.

App history

Remove recents inside one app

A messaging or social app can maintain its own emoji, sticker, reaction, or GIF history. Resetting the phone's keyboard may not affect that app-specific list.

How to manage recently used emojis on iPhone and iPad

Apple's emoji keyboard includes a Frequently Used category containing recently used emoji, Memoji, and stickers. Apple does not document a button for deleting one item from that category.

Use the low-risk method first

  1. Open any app that uses the standard Apple keyboard.
  2. Switch to the emoji keyboard.
  3. Use several different ordinary emojis that you are comfortable seeing.
  4. Return to the Frequently Used category and check whether the unwanted item has moved down or out of view.
  5. Repeat only as needed rather than resetting the whole keyboard immediately.

This changes the visible list gradually and does not remove messages, photos, contacts, or app content. It also avoids removing learned keyboard information that may still be useful.

Understand the keyboard dictionary reset before using it

Apple provides Reset Keyboard Dictionary under Settings > General > Transfer or Reset iPhone > Reset. Apple's documentation says this erases words added to the keyboard dictionary. It is a broader keyboard action, not a documented single-emoji delete control.

Important: Do not describe Reset Keyboard Dictionary as a guaranteed emoji-history-only cleaner. Apple officially describes the action in terms of the keyboard dictionary and custom words. Record any important text replacements or learned typing behavior before choosing a reset.

Do not confuse Memoji and stickers with standard emojis

The Frequently Used area can include more than Unicode emoji. If the unwanted item is a Memoji or sticker, hiding sticker-related controls or changing the feature that created it may be more relevant than resetting standard emoji usage. The exact options can vary with the iOS version and enabled keyboard features.

How to manage recent emojis in Gboard

Gboard can store on-device personalization and learned words. Google's troubleshooting documentation also explains that clearing Gboard app data or storage returns Gboard to its default state. These are broader actions than deleting one recent emoji.

Try replacement before reset

  1. Open Gboard's emoji panel in a normal text field.
  2. Confirm that the unwanted item appears in Gboard rather than only inside the app.
  3. Use other emojis to refresh the visible recent row.
  4. Close and reopen the keyboard before deciding that the list did not update.

Know the difference between two Gboard cleanup options

Action What the official documentation says Why caution is needed
Delete learned words Removes saved words used for spelling and predictions. It is not documented as a recent-emoji-only control.
Clear Gboard data or storage Resets Gboard to its default state. It can affect wider keyboard settings and personalization.
Clear cache Used as a troubleshooting step for Gboard problems. A cache cleanup is not a promised emoji-history deletion method.

On Android, menu names can differ by device manufacturer and software version. If Gboard is your only installed keyboard, make sure you can still enter text before uninstalling or disabling it.

How to manage recent emojis in Samsung Keyboard

Samsung Keyboard has separate controls for suggestions, learned words, keyboard settings, touch recognition data, and cache. Samsung's support documentation says that Erase personalized predictions removes data used for word predictions and learned words. It does not describe that control as a one-item recent emoji delete button.

Check the keyboard in this order

  1. Open the Samsung Keyboard emoji panel and confirm the item is in its recent area.
  2. Use other emojis to see whether the list naturally updates.
  3. If the problem is an unwanted suggestion, review the separate Suggest emojis setting.
  4. Use Reset to default settings only after reading each available reset option.
  5. Avoid selecting every reset option when only one behavior is bothering you.

Model differences: Samsung notes that screens and available settings can vary by carrier, software version, and device model. These instructions apply to the default Samsung Keyboard, not every third-party keyboard installed on a Galaxy device.

How to clear frequently used emojis on Mac

Mac provides the clearest official control in this guide. Apple's Mac documentation includes a command for clearing frequently used emoji and symbols from the Character Viewer.

  1. Press the Fn or Globe key with E, or choose Edit > Emoji & Symbols.
  2. Expand the Character Viewer if it is collapsed.
  3. Open the Action pop-up menu.
  4. Choose Clear Frequently Used Characters.
  5. Close and reopen the viewer to confirm the list has changed.

This command is more precise than resetting an entire phone keyboard. It targets the frequently used characters shown by the Mac Character Viewer. An individual app can still maintain a separate reaction or sticker history.

Can you clear recently used emojis in Windows?

Microsoft's current documentation confirms that the Windows emoji panel contains a Most recently used section and that the panel opens with the Windows key plus period. In the official material reviewed for this guide, Microsoft does not provide a documented command for removing one emoji or clearing only that recent emoji section.

Use other emojis to replace visible entries before trying system-level resets. Do not clear unrelated Windows activity, clipboard, account, or app data under the assumption that it is the same as the emoji panel's recent list.

Avoid registry edits and unknown cleanup tools: A recent emoji shortcut is not worth installing untrusted software or changing undocumented system values. Such changes can create a larger problem without reliably removing the item you intended.

Why the emoji can remain inside WhatsApp, Slack, Discord, or another app

Apps can show their own recent emoji, reaction, sticker, GIF, or custom workspace lists. These lists may be connected to an account, a server, a workspace, or local app data rather than the system keyboard.

Test the same keyboard in two apps. If the unwanted item appears only in one app, look for that app's own emoji or reaction settings. Do not reset the entire system keyboard until you have confirmed that the keyboard itself owns the list.

Keyboard list: The item appears in every app that opens the same keyboard.
App-only list: The item appears in one app's reaction picker but not in the phone keyboard.
Account list: The same recent reactions return after signing in on another device.

Clearing recent emojis does not delete sent messages

A recent emoji list is usually a shortcut for selecting characters. Removing or replacing entries in that list does not remove emojis from messages that were already sent, comments already published, documents, or screenshots. Delete or edit the original content separately when the app allows it.

The reverse is also true: deleting a conversation may not clear the keyboard's recent list. The message history and the input shortcut can be stored by different parts of the device or app.

A safer order of actions

  • Identify whether the item belongs to the system keyboard or one app.
  • Use other emojis first to refresh the visible recent list.
  • Restart the affected keyboard or app and check again.
  • Review the exact wording of any reset option before selecting it.
  • Back up text replacements or keyboard preferences you need.
  • Prefer a documented platform command over a third-party cleanup tool.
  • Do not clear unrelated activity or clipboard history.
  • Check whether the item is a sticker, Memoji, GIF, or custom reaction.
  • Remember that removing recents does not delete sent content.
  • Stop when the visible problem is solved instead of resetting more data.

Builder's note: While maintaining Mojitap's emoji browser, a useful troubleshooting rule is to separate the character from the interface that remembers it. The same emoji can be stored as a keyboard recent, an app reaction, a sticker, or part of a message. Testing the same text field in a second app usually reveals which layer needs attention.

Frequently asked questions

Can I delete one recently used emoji on iPhone?

Apple does not document a delete button for one item in the iPhone Frequently Used category. Use other emojis to replace visible entries before considering a wider keyboard reset.

Does resetting the iPhone keyboard delete messages?

Reset Keyboard Dictionary is a keyboard setting, not a message deletion command. It does not remove sent conversations, but Apple says it erases words added to the keyboard dictionary.

Will deleting learned words in Gboard clear recent emojis?

Google's documentation describes that option as deleting saved words. It does not promise that it clears only or all recent emoji entries. Treat it as a learned-word control rather than a guaranteed emoji fix.

Can Mac clear the whole frequently used emoji list?

Yes. Apple documents a Clear Frequently Used Characters command in the expanded Mac Character Viewer.

Why did the emoji return after I cleared something?

You may have cleared the system keyboard while the app maintains its own reaction history, or the list may be synchronized through an app account. Confirm which interface is showing the item.

Is a factory reset necessary?

No. A full device reset is disproportionate for a recent emoji list. Start with replacement, app-specific settings, or the narrowest documented keyboard action available.
