Why Does :) Turn Into an Emoji in Word or Outlook?

Written by Bavum, Builder and Editor at Mojitap · Published August 28, 2026 · Reviewed with current Microsoft documentation · About 9 minutes

Microsoft Word and Outlook can use AutoCorrect to replace a typed emoticon such as :) or :-) with a smiley emoji. To keep the text version once, press Ctrl+Z immediately after the conversion. To stop that specific replacement permanently, open AutoCorrect, search for the punctuation entry, and delete only that entry.

Do not turn off every AutoCorrect feature unless that is what you actually want. Removing the single smiley entry preserves other useful corrections, while disabling Replace text as you type stops a much wider set of replacements.

Why Word and Outlook change typed punctuation

Microsoft documents this as an AutoCorrect replacement. In supported desktop versions, typing :) or :-) can produce the color smiley emoji 😊. The typed characters are an emoticon; the replacement is a Unicode emoji character. They may look similar in a sentence, but they are not stored as the same text.

Item Example What it contains Why the difference matters
Typed emoticon :) A colon and a closing parenthesis It stays plain keyboard text when AutoCorrect does not replace it.
Converted emoji 😊 A Unicode emoji character Its artwork can vary by operating system, font, and app.
Legacy symbol Black-and-white smiley An older Wingdings-based character in legacy behavior It can look different from a current color emoji and may not transfer cleanly to other software.

Undo one conversion without changing any settings

If you usually want AutoCorrect but need one literal emoticon, the quickest method is to undo only the most recent replacement.

  1. Type the emoticon, such as :).
  2. Wait for Word or Outlook to convert it.
  3. Press Ctrl+Z immediately.
  4. Continue typing after the original punctuation returns.

This leaves the AutoCorrect rule available for future documents and messages. It is the least disruptive option when the problem occurs only occasionally.

Remove the smiley AutoCorrect entry in Word for Windows

  1. Open Word.
  2. Go to File > Options > Proofing.
  3. Select AutoCorrect Options.
  4. Open the AutoCorrect tab.
  5. In the Replace box, type :).
  6. Select the matching entry in the list.
  7. Select Delete, then confirm the dialog.
  8. Repeat the check for :-) if both forms are listed.

Deleting the entry is narrower than clearing Replace text as you type. Common spelling corrections and other saved replacements can remain active.

Remove the entry in Word for Mac

  1. Open Word and choose Word > Preferences.
  2. Open AutoCorrect.
  3. Locate the replacement entry for :) or :-).
  4. Select it and use the minus button to remove it.
  5. Close the settings and test in a new line of text.

Microsoft notes that the AutoCorrect list is shared by Office programs that support the feature. Removing an entry in Word can therefore affect another supported Office program that uses the same list.

Check the result in both Word and Outlook.

If you use both applications, test the same emoticon in each one after changing the entry. A change intended for Word may also alter Outlook's supported AutoCorrect behavior.

Remove the entry in Outlook for Windows

In desktop Outlook versions that provide the classic Options menus, Microsoft documents this route:

  1. Go to File > Options > Mail.
  2. Select Editor Options.
  3. Choose Proofing > AutoCorrect Options.
  4. In the Replace box, type the unwanted emoticon.
  5. Select the matching entry and choose Delete.

If your Outlook interface does not contain File > Options, do not assume the menu is hidden. Outlook versions and interfaces differ. Use Ctrl+Z for a one-time correction, or open a supported desktop Office app to manage the shared AutoCorrect list when Microsoft provides that option.

Outlook for Mac and legacy Outlook for Mac

Microsoft separates current and legacy Outlook for Mac controls. Current Outlook for Mac provides text-replacement controls under Outlook > Settings > Spelling & Typing. Legacy Outlook for Mac uses Outlook > Settings > AutoCorrect and the Replace text as you type setting.

Microsoft also states that new Outlook for Mac does not support adding or removing individual AutoCorrect entries. If the individual entry controls are absent, do not follow instructions for legacy Outlook as though the same screen must exist.

Word for the web and Outlook on the web

Word for the web can automatically convert several typed emoticons and offers a smaller set of AutoCorrect controls than desktop Word. It lets you reach AutoCorrect options from Review > Editor > AutoCorrect Options, but Microsoft says the web version cannot add or remove individual entries from the AutoCorrect list.

Outlook on the web also does not provide the same individual AutoCorrect entry management as supported desktop versions. When you need a permanent, entry-specific change, Microsoft directs users to a desktop Office application that supports editing the list.

Web limitation:

If you only need the literal emoticon once, undo the conversion immediately. Do not disable every replacement merely because the web version lacks a button for deleting one entry.

Why the smiley becomes a box

Microsoft says a punctuation sequence that changes into a box instead of an emoji can indicate that the Segoe UI Emoji font is missing or damaged on Windows. The font is included with Windows 8 and later. Microsoft's documented repair path is the Windows System File Checker, not downloading an unknown emoji font from a third-party website.

  1. Test the same emoji in another current Office document.
  2. Update Windows and Office.
  3. Check whether ordinary text and older emojis display normally.
  4. Use Microsoft's System File Checker guidance if a Windows system font may be damaged.
  5. Avoid installing unverified font packs or keyboard extensions.

If boxes or question marks also appear outside Word and Outlook, use Why Does an Emoji Show as a Box or Question Mark? to separate a font problem from unsupported characters, damaged text, and broken emoji sequences.

Why the smiley is black and white

Microsoft explains that older Office versions and Windows 7 used a Wingdings character for some smiley replacements. That legacy character is black and white, while current behavior uses a Unicode emoji rendered through an emoji-capable font.

A black-and-white face is therefore not always a failed conversion. Check the Office version, Windows version, and the character's font before replacing the text repeatedly. If the document must work across old systems, keeping the literal emoticon can be more predictable than depending on one visual style.

Restore the smiley replacement later

If you change your mind, return to the AutoCorrect tab and add the entry again. Enter the emoticon in the Replace field, insert the desired emoji in the With field, and choose Add. Test the result in a new document before relying on it in both Word and Outlook.

Final check

  1. Use Ctrl+Z when you only need to undo one conversion.
  2. Delete the specific AutoCorrect entry when you want a permanent narrow fix.
  3. Turn off Replace text as you type only when you want broader AutoCorrect changes.
  4. Remember that supported Office programs can share the AutoCorrect list.
  5. Do not expect web, current Mac, legacy Mac, and Windows menus to be identical.
  6. Treat a box as a font or rendering problem, not simply an unwanted replacement.
  7. Check for legacy Wingdings behavior when the result is black and white.
  8. Keep important meaning in words when the document will be shared across different systems.
