Emoji Inspector: See the Unicode Inside an Emoji

Paste an emoji, symbol, or short piece of text to see the exact Unicode code points that make it up. This is useful when two characters look almost identical, an emoji turns black and white after pasting, a joined emoji falls apart, or a flag or skin-tone sequence behaves differently in another app.

Local processing: the inspector below runs in your browser. Mojitap does not send the pasted value to a Mojitap text-processing server. Analytics and hosting have separate behavior described in the Privacy Policy.

Sequence diagnostics

    How to read the result

    An emoji can be one Unicode code point or a sequence of several code points. What looks like one picture on screen may contain invisible characters that control presentation or join several visible emoji together.

    • U+FE0F (VS16) requests emoji presentation for characters that have a standardized emoji variation sequence.
    • U+FE0E (VS15) requests text presentation for those standardized variants.
    • U+200D (ZWJ) joins supported emoji components into a combined sequence. An older app can show the parts separately if it does not support the full sequence.
    • U+1F3FB–U+1F3FF are emoji skin-tone modifiers. They normally follow a supported person or body-part emoji.
    • U+1F1E6–U+1F1FF are regional indicator symbols used in pairs for many country-flag sequences.
    • U+20E3 is the combining enclosing keycap mark used in keycap sequences.
    What this tool cannot prove: it shows the text structure you pasted. It does not predict the exact artwork that every phone, browser, font, or app will display, and it does not turn an unsupported sequence into a supported one.

    Common troubleshooting paths

    If a recognizable symbol changes from color to black and white, compare the code points for U+FE0F or U+FE0E and then compare the destination app or font. If the character becomes a box or question mark, the more likely issue is missing character or sequence support. If one picture separates into several emoji, look for U+200D and test the same complete sequence in a current app.
