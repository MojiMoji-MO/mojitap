About Mojitap

Mojitap is an independent emoji tool maintained by Bavum, Builder and Editor at Mojitap. It has two main uses: suggesting existing Unicode emoji for a draft and finding a specific emoji to copy. Neither requires installing a keyboard extension or creating an account.

What the tool actually does

The homepage runs a local JavaScript rule engine. It looks for supported English and Korean phrases, checks common negation and status patterns, and adds optional emoji without rewriting the original words. It limits repetition and can leave a sentence unchanged when it does not find a suitable match.

This is not a language-model service. It does not understand every joke, dialect, relationship, or cultural implication. A suggestion is an editing option, not evidence that a message is appropriate to send. Sensitive passages and unclear sentences may receive no additions.

The All Emojis page is a searchable character list. Emoji artwork depends on the browser, operating system, font, and destination app. Copying a character does not guarantee identical artwork on another device.

How the guides are prepared

The guides explain emoji input, compatibility, reactions, meaning, and clear use in messages. They combine linked official documentation with original explanatory examples, comparisons, and troubleshooting sequences.

AI-assisted drafting and coding tools are used in creating and revising this site. They are not used to process text entered into the homepage editor. Device instructions are documentation-based unless a guide identifies a particular test environment. Local browser checks do not demonstrate behavior on every phone, keyboard, or third-party app.

Sample messages are illustrative unless explicitly identified otherwise. They are not customer case studies, measured marketing results, or claims of professional qualifications. When platform controls change, the linked official documentation provides the reference for the feature being discussed.

Privacy and data

Your draft is processed by the homepage's code in your browser, not submitted to a Mojitap text-processing server. The website uses third-party services for analytics, advertising, hosting, and contact messages. Those services have separate data behavior; see the Privacy Policy before using the site.

Corrections and contact

For an incorrect instruction, broken symbol, or access problem, use the contact page or email info.mojitap@gmail.com. Include the page address and, for display problems, the app, operating system, and an example without personal information. Do not send passwords, private messages, or confidential documents.
