How the number of emoji is chosen

The tool normally adds one cue to a matched sentence and limits additions within a paragraph. A long sentence can receive two compatible topic cues. A document-wide ceiling limits clutter; it is not a target the tool must fill. Existing emoji and repeated sentences reduce new additions.

The same input uses stable selection rather than unrelated random decoration. A sentence that already contains emoji is left alone. Clicking the button repeatedly is not intended to keep adding more symbols; use the palette for intentional additions.

What stays untouched

The engine preserves your words, punctuation, and line breaks. It excludes supported URL, email, mention, hashtag, and code patterns from topic matching. This is not a general-purpose parser or a guarantee for every markup format. Do not paste secrets or use decorative processing for program source, legal wording, or other exact-format material.

How the engine handles difficult wording

For ordinary English and Korean text, the engine falls back to broad context cues when no narrow topic rule wins. Negation, cancellation, failure, and sensitive wording are handled before positive or promotional cues so the added emoji does not reverse the sentence. Existing emoji and protected URL, email, code, mention, and hashtag patterns are preserved. Mojitap still does not interpret every form of sarcasm, metaphor, or complex condition like a human reader, so review the result before publishing.

Insert and copy

Select a palette emoji to insert it at the cursor. The original single-emoji clipboard copy is also attempted; a copy restriction does not prevent insertion. Copy All copies the editor text and reports a failure rather than claiming success when the browser blocks it. Clipboard behavior depends on browser permissions.

Find the right guide

For a particular character, use All Emojis. For an unknown name, try the description-based search guide. A box or broken sequence is covered by display troubleshooting. For device input, see the keyboard guide.
