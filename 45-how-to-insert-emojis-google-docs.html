How to Insert Emojis in Google Docs: Shortcuts and Fixes

Written by Bavum, Builder and Editor at Mojitap · Published August 19, 2026 · Reviewed with current Google, Microsoft, and Apple documentation · About 10 minutes

To insert an emoji in Google Docs on a computer, place the cursor in the document and choose Insert > Symbols > Emoji. You can also type @emoji and press Enter, or type a colon followed by a search term, such as :cat, and choose a result. Windows and Mac system emoji shortcuts also work in many editable Google Docs fields.

If an emoji does not appear, becomes a box, or the wrong emoji tool opens, first identify whether you are inserting a text character, adding a collaboration reaction, or pasting an image-style sticker. Those actions look similar but use different controls and fail for different reasons.

Google Docs emoji methods at a glance

Insert menu

Insert > Symbols > Emoji

The most direct Google Docs method. It opens the built-in emoji picker and lets you search by a word.

@ menu

@emoji

Type @emoji, press Enter, then choose or search for the emoji you want.

Colon search

:cat

Type a colon and a search term. Google Docs can show matching emoji suggestions directly in the document.

System shortcut

Windows + . / Fn + E

Windows opens its emoji panel. On Mac, use Fn/Globe + E or Edit > Emoji & Symbols.

Choose the right emoji method for the task

What you want to do Best method What it creates Common confusion

React to selected text Add emoji reaction A collaboration reaction connected to the selected content It is not part of the document's normal text
React to a comment Hover over the comment and add a reaction A reaction connected to that comment Removing your reaction does not remove other people's reactions

Method 1: Insert an emoji from the Google Docs menu

  1. Open a Google Doc in a web browser.
  2. Click the exact position where the emoji should appear.
  3. At the top, choose Insert.
  4. Choose Symbols, then Emoji.
  5. Select an emoji or enter a search term.
  6. Read the full sentence again before sharing or exporting the document.

This method is useful when you do not know the operating-system shortcut or want the picker that Google Docs provides inside the editor. Search for the visible object or intended function, such as check, warning, calendar, idea, or smile.

Method 2: Type @emoji inside the document

  1. Place the cursor on an empty line or inside a sentence.
  2. Type @emoji.
  3. Press Enter when the emoji option appears.
  4. Browse the list or enter a search term.
  5. Select the result to insert it as text.

The @ menu is useful when your hands are already on the keyboard. It avoids opening the top menu, but it still inserts a standard emoji rather than a Google Docs reaction.

Do not treat @emoji as a universal keyboard shortcut.

It is a Google Docs editor feature. The same typed command may do nothing in another website, a plain-text editor, or an email client. Use the operating-system picker when you need a method that works across many applications.

Method 3: Search with a colon

Google Docs can search for emoji as you type a colon followed by a search word. For example:

Search by object

:cat

Use a visible noun when you know what the emoji depicts.

Search by purpose

:warning

Use a function or message status when the visual form is less important than the meaning.

If colon suggestions appear when you do not want them, Google documents a way to disable this behavior:

  1. Open the Google Doc.
  2. Choose Tools > Preferences.
  3. Clear Insert emojis using the colon character.
  4. Save the preference and test the same colon text again.

Turning off colon insertion does not remove the Insert menu, @emoji, the Windows emoji panel, or the Mac Character Viewer. It only stops the colon-based Google Docs behavior.

Use Windows or Mac emoji shortcuts in Google Docs

Google Docs can accept standard emoji from the operating system while the cursor is in an editable document field.

  • Windows: press Windows + . (period) to open the emoji panel.
  • Windows alternative: Microsoft also documents Windows + ; (semicolon).
  • Mac: press Fn/Globe + E or choose Edit > Emoji & Symbols.
  • If a system shortcut does not work in Docs, use Insert > Symbols > Emoji to determine whether the problem is the keyboard shortcut or the document.

For a complete desktop shortcut guide, see Windows and Mac Emoji Shortcuts . For all major phone and computer keyboards, use How to Type Emojis on Windows, Mac, iPhone, and Android .

Inserted emoji and emoji reactions are different

Google Docs also supports emoji reactions for collaboration. With comment or edit permission, a user can react to selected text in a Google Doc or react to comments in Docs, Sheets, and Slides. These reactions are attached to collaboration activity rather than inserted into the normal document text.

Feature Where it appears How to remove it What happens when copied
Inserted emoji Inside the document text Delete it like another character Usually copies as Unicode text
Reaction to selected text In the collaboration margin or reaction interface Click your reaction again; selected-content reactions can also be resolved It is not part of the copied document text
Reaction to a comment Attached to the comment Click your reaction again It remains collaboration metadata rather than document content

Permissions matter for reactions.

Google says emoji reactions require comment or edit permission. If the reaction control is missing but normal emoji insertion works, check the document permission and the selected feature before troubleshooting the keyboard.

Why an emoji does not insert or display correctly

1. The cursor is not in editable document text

Click in the document body and type a normal letter first. If you cannot type, the problem is document access or the active interface, not the emoji picker. Viewer access does not provide normal text editing.

2. Colon emoji insertion was turned off

If :cat stays as plain text, check Tools > Preferences. The colon option can be disabled without affecting other emoji methods. Use @emoji or the Insert menu when you want to keep colon conversion off.

3. You are looking for a reaction instead of document text

Select text and check the collaboration controls only when you want a reaction. Use the Insert menu or keyboard picker when the emoji must appear in the document itself.

4. The emoji becomes a square or question mark

A missing-character box usually means the device, browser, exported format, font, or destination app does not support the character. Try a more widely supported emoji and compare the same document in a current browser. For a detailed diagnosis, see Why Does an Emoji Show as a Box or Question Mark? .

5. A pasted item behaves like an image

A sticker, GIF, or image copied from another app is not the same as a standard Unicode emoji. Delete the image-style item and insert a character through Google Docs or copy a standard emoji from Mojitap.

6. Emoji search does not find the expected result

Search terms do not always match the informal name you remember. Try the visible object, action, emotion, color, or an official Unicode keyword. The guide How to Find an Emoji When You Don't Know Its Name provides a structured search method.

7. The emoji looks different after export or sharing

Standard emoji artwork is supplied by the operating system, browser, font, or receiving application. The character can remain valid while its artwork changes. Keep the important meaning in words when appearance differences could change the interpretation.

Use emoji without weakening the document

Emoji can support scanning, but a document should still make sense when the emoji is removed. Use words for status, responsibility, dates, and instructions.

What Mojitap can and cannot do

Mojitap can help you find and copy standard Unicode emoji or review browser-based emoji suggestions for a sentence. It cannot change Google Docs permissions, enable collaboration reactions, alter Docs preferences, or force every exported file and device to display the same artwork.

Final Google Docs emoji check

  1. Decide whether you need document text or a collaboration reaction.
  2. Use Insert, @emoji, colon search, or the system picker for text.
  3. Check Tools > Preferences if colon search is disabled or unwanted.
  4. Confirm that you have edit permission before troubleshooting insertion.
  5. Confirm comment or edit permission before troubleshooting reactions.
  6. Use a standard Unicode emoji when the content must remain editable text.
  7. Keep important instructions, status, and deadlines in words.
  8. Test the exported or shared result when exact compatibility matters.
