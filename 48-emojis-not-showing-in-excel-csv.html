Emojis Broken in Excel or CSV? Fix Imports, Exports, and Display

Written by Bavum, Builder and Editor at Mojitap · Published October 26, 2026 · Based on Microsoft Excel and Unicode documentation

If an emoji looks fine in an Excel workbook but turns into strange letters after you open a CSV, check how Excel read the file before changing the emoji or its font. An emoji such as 📦 can survive a UTF-8 CSV export perfectly and still appear as ðŸ“¦ when its bytes are interpreted using the wrong character encoding.

A square, a missing character, and a combined emoji that splits into two are different failures. The fix depends on when the text changed. This guide starts with that distinction instead of asking you to reinstall fonts or replace every emoji.

What to do first

Do not save over the original file yet. Keep the source CSV and an .xlsx working copy. In desktop Excel, use Data → From Text/CSV, choose UTF-8 as the file origin or encoding when that control appears, verify the preview, and only then load the data. If the preview is already wrong, importing it repeatedly will not recreate characters that are missing from the source file.

Start with the original text rather than the cell's appearance. For example, a file can store a correct Unicode sequence even when Excel or the operating system chooses an unexpected symbol or monochrome design.

Insert an emoji into an Excel cell

For an ordinary Unicode emoji, you do not need to insert a picture. Put the cell in edit mode, then use the system character picker:

Windows

Select the cell, enter edit mode (for example, double-click it), and press Windows + . (period). Choose or search for an emoji in the Windows panel. You can also type it in a plain-text field and paste the resulting characters into the cell.

Mac

Place the insertion point in the cell and open Character Viewer using Control + Command + Space or Fn + E where supported. Pick an emoji, then check it in the cell and formula bar. The available shortcuts and picker layout depend on macOS settings.

If the emoji is already in the cell and only changes after a CSV round trip, the keyboard shortcut is not the problem. Move to the import steps below. If you inserted a picture, icon, or sticker, that object is not the same as Unicode text and should not be expected to survive a plain-text CSV export.

Open an emoji-containing CSV without guessing its encoding

  1. Preserve the source file. Save a copy before opening it in Excel. Do not overwrite it if the first view contains garbled characters.
  2. Open Excel and use the import command. On supported desktop versions, choose Data → From Text/CSV (sometimes under Get Data → From File) and select the copied file.
  3. Check the preview before loading. Choose UTF-8 for the file origin or encoding where the option is shown. Confirm that both letters and emoji look sensible. In some versions, Excel detects UTF-8 automatically; the available controls vary.
  4. Confirm the delimiter separately. If the file has comma-separated columns, check that the preview uses commas as separators. An encoding problem and a delimiter problem can happen together, but changing a separator will not repair broken Unicode.
  5. Load the table, then save an .xlsx copy. Inspect a few representative values. Keep the original CSV for comparison if you need to identify where the text changed.

Microsoft explains that UTF-8 CSV files with a byte order mark (BOM) can typically be opened normally, while files without that mark may need the text/CSV import flow. A BOM helps identify an encoding; it is not an emoji character and it does not repair text that was already lost.

Save your Excel work without losing characters or sheets

Keep the main working file in .xlsx format. It preserves workbook features that CSV cannot represent. If another application requires a CSV, export a separate copy using File → Save As (or the applicable export command) and choose CSV UTF-8 (Comma delimited) when that option is available. Do not silently substitute an older or unspecified CSV encoding for a Unicode-heavy file.

Microsoft notes that saving as CSV exports only the active worksheet and discards formatting and many workbook features. A CSV also carries plain text values rather than embedded emoji images, cell color choices, or workbook formulas as formulas. Keep your original .xlsx file; do not treat a CSV copy as a backup of the whole workbook.

After exporting, import the newly saved CSV back into a fresh workbook and compare the text with the original. If a value is already wrong in the export, change the export settings or return to the good workbook. If the exported text is correct but only looks wrong on reopening, focus on import settings and display support.

When a character has already been replaced: if the raw source file contains a literal ? where an emoji should be, changing the import encoding generally cannot reconstruct the missing character. Recover it from an earlier workbook, the original app, or a known-good export. Do not overwrite the only good copy while experimenting.

A split emoji is not always a CSV problem

A single-looking emoji may contain multiple Unicode code points. The developer sequence 👩‍💻 consists of U+1F469 (woman), U+200D (zero width joiner), and U+1F4BB (laptop). The joiner is invisible. If it is removed during editing, the parts can appear separately. Even with the joiner present, a system without support for that sequence may display separate components.

Paste the intact version and the exported version separately into the Mojitap Emoji Inspector. If one lacks U+200D, look for a step that removed or altered the text. If both have the same code points, check the receiving app or font instead. The Inspector shows code points in the pasted text; it cannot guarantee how every application will draw them.

The distinction matters because setting a CSV to UTF-8 cannot make an older emoji font support every combined symbol. Likewise, changing fonts cannot restore bytes that were misdecoded and then saved as different characters.

Choose the fix that matches your file

  • Editing a workbook: use a Unicode emoji character in an ordinary cell, keep an .xlsx copy, and check the formula bar if rendering looks strange.
  • Receiving a CSV: preserve the original file, import as UTF-8, review the preview, and confirm the delimiter separately.
  • Sending a CSV: export as UTF-8 where supported, then independently reopen the output and inspect representative cells. Keep the Excel source file.
  • Working with a joined sequence: compare the complete Unicode sequence before assuming the emoji data was lost.

If a document or message fails in a way unrelated to Excel or CSV encoding, use the wider emoji copy-and-paste troubleshooting guide. For missing glyphs rather than garbled text, see why an emoji appears as a box or question mark.
